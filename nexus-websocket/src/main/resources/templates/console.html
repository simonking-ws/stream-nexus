推送消息

走 REST 接口 /ws/push；业务系统接入也是调这个接口

消息日志

下行：CONNECTED 建连回执 · MESSAGE 业务消息 · PING 心跳（客户端自动回 PONG）

接入说明

1. 终端（浏览器 / H5 / App）连 ws://host:9090/ws?modules=test，只负责收消息；
2. 客户端ID 由服务端在握手时生成（UUID），随 {"event":"CONNECTED"} 回执下发给终端，前端不需要传任何标识；
3. 业务系统调用 REST 接口 POST /ws/push （请求头 X-Ws-AppId / X-Ws-Key）即可推送，无需编写任何 Netty 代码；
4. 两个端口在同一进程内共享连接注册表：REST 收到推送 → 查注册表 → 直接写 WebSocket 通道；
5. 客户端ID 重连即换：要按用户维度稳定寻址请用模块订阅， 或在业务系统侧维护「用户 → 当前 clientId」的映射（终端建连后上报）；
6. 心跳是应用级的（浏览器收不到协议层 ping/pong 帧），客户端收到 {"event":"PING"} 必须回 {"event":"PONG"}。
