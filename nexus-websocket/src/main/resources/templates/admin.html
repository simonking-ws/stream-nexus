暂无 TCP 接入连接：业务系统引入 nexus-client SDK 后连此端口

TCP 接入（端口 9091）是业务系统侧的长连接推送通道， 与终端的 WebSocket（端口 9090）分属两条流水线、两张注册表： 终端连 WS 收消息，业务系统连 TCP 交消息，协议在建连那一刻就定了，不存在混连。 这里只做观测，不提供强制下线——一条 TCP 连接背后是一整个业务系统， 掐断它等于掐断它的推送链路（终端连接可在「连接台账」里单条下线）。
